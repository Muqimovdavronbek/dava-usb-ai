DAVA USB AI - START HERE

A local text assistant using a complete Qwen3 4B Q4_K_M model and llamafile engine. The complete release package includes the engine and model; the source archive does not.

ASSEMBLE
Keep the assembly ZIP and all .001-.005 parts in one directory. Extract the assembly ZIP and run TAYYORLASH_KALI.sh or TAYYORLASH_WINDOWS.cmd. Checksums are verified.

COPY
Copy the entire generated Dava_USB_AI directory to a USB drive with at least 3 GB free. Keep model, bin and web directory names intact. Do not launch from inside a ZIP.

LINUX x64
    bash BOSHLASH_KALI.sh
The launcher uses Python 3 and ordinary system utilities. On a noexec drive, launch through Bash; a temporary local executable copy is used while the large model stays on the drive.

WINDOWS 10/11 x64
Open BOSHLASH_WINDOWS.cmd.
Follow your organization's application-execution policy on managed computers.

USE
Wait for the ready message and open the address shown, normally http://127.0.0.1:8765/.
Enter sends a message; Shift+Enter inserts a line. Stop interrupts a response. New conversation clears the current conversation, so export anything needed first.

The model runs on the CPU. Loading and response time depend on memory, processor and drive speed. Keep the terminal open while using the chat.

MOVE CONVERSATIONS
Browser history is not automatically written to the USB drive. Export JSON, save it on the drive and import it on the next computer. Clear a shared browser's conversation when finished.

FINISH
Press Ctrl+C in the launcher terminal. Safely eject the USB drive after the process stops.

REQUIREMENTS
Intel/AMD x64 Linux or Windows 10/11.
8 GB RAM recommended; about 4 GB free for the model.
Recent browser.
Text only: no web search, image, microphone or video analysis.
Check generated answers independently.

TROUBLESHOOTING
Missing model: verify that the complete release was assembled and copied.
Out of memory: close other heavy programs.
Integrity concern: run the supplied verification script.
Server unavailable: check that the launcher terminal remains open.
Inspect logs/ for the current run.

Engine: llamafile 0.10.6-thin. Model: Qwen3 4B Q4_K_M.
Original interface and launchers use MIT. Existing engine/model licenses remain under licenses/.
