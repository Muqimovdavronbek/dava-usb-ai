# Quick start

1. Open the repository's Releases page.
2. Download `Dava_USB_AI_Yigish.zip` and all five `.001`–`.005` parts into one directory.
3. Extract the assembly ZIP. Do not extract each numbered part separately.
4. Run `bash TAYYORLASH_KALI.sh` on Linux or `TAYYORLASH_WINDOWS.cmd` on Windows.
5. Copy the complete resulting `Dava_USB_AI` folder to the USB drive.
6. Run `bash BOSHLASH_KALI.sh` or `BOSHLASH_WINDOWS.cmd`.
7. If the browser does not open, use the ready address printed by the terminal, normally `http://127.0.0.1:8765/`.
8. Keep the terminal open. Finish with `Ctrl+C`, then safely remove the drive.

Recommended: 8 GB RAM, at least 3 GB free USB storage and about 5.1 GB free assembly space on the computer.

Conversations stay in browser storage. Export a JSON file to carry them to another computer and import it there.

The earlier native model test was on Linux x64; Windows behavior remains separately unverified. Existing video files remain unchanged.
