# DAVA USB AI — Qadamlar va manzillar

1. [Tayyor paket](https://github.com/Muqimovdavronbek/dava-usb-ai/releases/tag/v1.0.0) sahifasini oching.
2. `Dava_USB_AI_Yigish.zip` va barcha `.001`–`.005` qismlarni bir papkaga yuklang.
3. Kichik Yigish ZIPini oching. Qismlarni alohida ochmang.
4. Kali’da yig‘ish papkasida terminal oching:

```bash
bash TAYYORLASH_KALI.sh
```

5. Chiqqan `Dava_USB_AI` papkasini butunligicha fleshkaga ko‘chiring.
6. Fleshkadagi shu papkada terminal oching:

```bash
bash BOSHLASH_KALI.sh
```

7. Brauzer ochilmasa, terminaldagi `TAYYOR` qatoridagi manzilga kiring. Odatda `http://127.0.0.1:8765/`.
8. Tugatgach terminalda `Ctrl+C` bosing, keyin fleshkani xavfsiz ajrating.

Windows’da yig‘ish uchun `TAYYORLASH_WINDOWS.cmd`, ishlatish uchun `BOSHLASH_WINDOWS.cmd` fayli ochiladi.

Suhbatlarni fleshkaga avtomatik yozmaydi. `Suhbatni saqlash`dan JSON oling va fleshkaga saqlang. Boshqa kompyuterda `Suhbatni ochish`dan foydalaning.

## Rasmiy manbalar

- Dastur: https://github.com/mozilla-ai/llamafile/releases/tag/0.10.6
- Model: https://huggingface.co/Qwen/Qwen3-4B-GGUF
- Kodlar: https://github.com/Muqimovdavronbek/dava-usb-ai
- To‘liq paket: https://github.com/Muqimovdavronbek/dava-usb-ai/releases/tag/v1.0.0

Tavsiya: 8 GB RAM, bo‘sh 4 GB fleshka. Yig‘ish kompyuterda bajariladi; qo‘shimcha 5.1 GB joy kerak.

Video o‘zbekcha sun’iy ovoz, rasmiy saytlarning ko‘rinishlari, haqiqiy Linux sinovidagi dastur oynalari va izohli buyruq kartalaridan tuzilgan. Jismoniy fleshka ulash tasvirlanmagan. Windows qismi qo‘llanma sifatida ko‘rsatilgan, amaliy Windows sinovi bajarilmagan.
