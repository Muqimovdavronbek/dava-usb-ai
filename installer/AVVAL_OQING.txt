DAVA USB AI - COMPLETE PACKAGE ASSEMBLY

The complete engine/model archive is approximately 2.45 GB, split into five parts for distribution. Download every part and the assembly ZIP into the same directory.

Extract the assembly ZIP. Do not extract numbered parts individually.
Linux: bash TAYYORLASH_KALI.sh
Windows: TAYYORLASH_WINDOWS.cmd

The scripts combine and verify the parts before extracting the application. Keep roughly 5.1 GB free on the assembly computer. After successful assembly, copy the complete Dava_USB_AI directory to a USB drive with at least 3 GB free.

Start from the generated application folder:
Linux: bash BOSHLASH_KALI.sh
Windows: BOSHLASH_WINDOWS.cmd

The normal browser address is http://127.0.0.1:8765/, but always use the launcher's actual output. Keep the terminal open.

Do not rename model/bin/web folders. Use the supplied verification script if files may be damaged. The source-only GitHub archive does not contain the complete model.

See the repository README for usage, requirements and license information.
